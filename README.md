# Chat Analysis Agent

This is a Flask application that analyzes chat data from a CSV file. It provides insights into user questions, bot replies, and potential areas for optimization.

## Features

*   **CSV Upload:** Upload a CSV file containing chat data.
*   **Paste Data:** Paste CSV data directly into a text area.
*   **Data Analysis:** The application performs the following analysis:
    *   **Optimization Category:** Categorizes questions into "System Issue," "UI Issue," "Unclear Answer," or "General Inquiry."
    *   **Sentiment Analysis:** Performs a simulated sentiment analysis on user questions.
    *   **Question Summary:** Summarizes the frequency of different question categories.
    *   **Effective Replies:** Identifies and counts effective vs. ineffective bot replies.
*   **Visualizations:** Displays the analysis results using charts and a data table.

## Getting Started

Follow the instructions in `AGENTS.md` to run the application.
